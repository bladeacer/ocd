# [0.11.0]

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Added

- `ocd check` parses the target app.css once and reuses the parsed index for
  both the variable comparison and the selector comparison. Previously the
  stylesheet was parsed twice, once for each check. A theme folder still
  reads every `*.css` below it, while a single stylesheet path reads just
  that file, so the reported CSS file count differs by design.

## Changed

- Test coverage across the source code is back up to 100%. New coverage
  tests were added for the cache, config, sources, and core packages so
  every statement is exercised by the test suite.

## Fixed

- None.
