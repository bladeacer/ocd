# Changelog - v0.6.0

## Overview

This release fixes a critical bug in the `origin` command where CSS variables and
selectors in cached versions missing from the RSS feed were never searched,
causing false "not found" results. It also improves CSS comment handling in the
origin parser so that definitions within CSS comments are correctly ignored.

## Planned for v0.6.0

- [x] Note the version where each Obsidian-specific variable/selector was introduced, so we can easily check backwards compatibility. Have strict or relaxed compat check which we can supply to parse target `theme.css`. Strict fails the moment a version higher than the target one is required. Relaxed just warns.
- As a bonus we get to have more robust tldr stat and similar output, and can extend this to the existing `check` command.
- We also want to caveat that the first version where a variable is introduced does not equate to the first version the variable is used significantly or extensively enough. That very much depends on the type of CSS the dev team is writing.

## Fixes

### Merge cached CSS versions with RSS public desktop versions

The `origin` command now merges version lists from two sources:

1. **RSS feed** - public, non-insider Desktop releases.
2. **CSS cache** - extracted `app.css` directories under `.obsidian_cache/css/`.

Previously, when a version was present in the CSS cache but absent from the
RSS feed (common when the RSS metadata is stale), the origin command silently
skipped that version, leading to incorrect "not found" results. Now all cached
versions are searched in addition to RSS-derived versions.

### Strip CSS comments before selector/variable search

Both `ContainsSelector` and `ContainsVariable` now strip CSS comments
(`/* ... */`, including multi-line) before matching. This prevents false
positives when a selector or variable name appears only in a comment.

### Files Changed

- `internal/core/origin.go` - Added `stripCSSComments` and `MergeVersions`
  functions; updated `ContainsSelector` and `ContainsVariable` to strip
  comments first.
- `internal/core/origin_test.go` - Added tests for `stripCSSComments`,
  `MergeVersions`, and comment-stripping behaviour in `ContainsSelector` and
  `ContainsVariable`.
- `cmd/origin.go` - Updated version resolution to merge RSS and cached
  versions.
- `cmd/origin_test.go` - Added `TestOriginCmdStaleRSS` integration test.

No configuration changes are required for this release.
