# [0.6.0]

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Added

- Compatibility check engine in `internal/core/compat.go`: `FindOrigins`
  scans cached `app.css` versions and returns the earliest version where each
  target selector or CSS variable was introduced. `CheckCompatibility` runs a
  strict or relaxed check against a target version, reporting violations,
  warnings, and unknown targets. Both functions include `String`, `MarshalJSON`,
  `MarshalYAML`, and `MarshalTOML` methods.
- `--compat-mode` flag on `ocd check <version> <theme.css>`: when set to
  `strict` or `relaxed`, the command runs `CheckCompatibility` on the theme's
  CSS variables against the target version, using all cached versions as the
  origin search space. The compatibility result is printed to stdout alongside
  the existing variable report. In strict mode, an incompatible result yields a
  non-zero exit code.
- `check_compat_mode` config key (`internal/config/config.go`) for the
  `--compat-mode` flag default.
- Batch `FindOrigins` returns a `TargetOrigin` for each target in a single pass
  through sorted cached CSS.

## Changed

- `CheckCompatibility` now sets `Compatible=false` when there are unknown
  targets (not found in any cached version) in strict mode. Unknown targets
  represent a potential risk and are treated as a violation.
- `ContainsSelector` and `ContainsVariable` now strip CSS comments
  (`/* ... */`, including multi-line) before matching, preventing false
  positives from commented-out definitions.
- `MergeVersions` in `internal/core/origin.go` merges RSS public desktop
  versions with cached CSS directory versions, so stale RSS feeds no longer
  cause false "not found" results.
- Configuration reference (`docs/CONFIG.md`) and `.ocd.toml` updated with the
  `check_compat_mode` key.

## Fixed

- Unknown targets in strict mode now make the compatibility result
  incompatible, matching the behaviour expected by
  `TestCheckCompatibilityEmptyVersions`.
