# [0.5.0]

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Added

- `ocd origin <selector|variable>`: find the earliest known public desktop
  Obsidian version where a selector or CSS variable was first introduced.
  Searches cached `app.css` across versions from the RSS changelog,
  filtered to public (non-insider) Desktop releases and sorted by semver.
  Targets starting with `--` are auto-detected as CSS variables; use `--`
  as a separator to pass them as arguments.
- `origin` command supports `--format` (toml/json/yaml), `--output`, and
  `--refresh` flags, with `origin_format` and `origin_dir` config keys.
- `PublicDesktopVersions`, `SortVersions`, `ContainsSelector`,
  `ContainsVariable`, `ListCachedVersions`, and `FindOrigin` helpers in
  the `core` package, all with full unit-test coverage.
- `OriginResult` type with `String`, `MarshalJSON`, `MarshalYAML`, and
  `MarshalTOML` methods.

## Changed

- README commands table updated to include `origin`.
- Configuration reference (`docs/CONFIG.md`) and `.ocd.toml` updated with
  `origin_format` and `origin_dir` keys.
