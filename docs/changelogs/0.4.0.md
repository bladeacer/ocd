# [0.4.0] — Unreleased

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Added

- Configuration file support, with OS-aware location resolution
  (`$XDG_CONFIG_HOME/ocd`, `~/.config/ocd`, or the current working
  directory's `.ocd.toml`). Direct command-line flags take priority
  over the working directory config, which takes priority over the
  global config.
- `ocd check` command: extract the CSS variables from a target Obsidian
  version and report which variables are missing from a local theme
  file. Output goes to stdout, or to a file with `--output`.
  File export defaults to the current working directory.
- Generalised file-output helper used by `stat`, `tldr`, and `check`
  so all three commands share one export path.
- `stat`, `tldr`, and `check` commands now default file export to
  the current working directory. Use `--output` or `output_dir`
  in config to specify a target directory.
- `h` and `l` keys in the diff viewer for moving between hunks, in
  addition to the existing `{` and `}` keys.
- `--tldr-output` and `--output` flags now accept a directory that is
  created if it does not exist.

## Changed

- Diff viewer help overlay updated to list the new hunk keys.
- README and this changelog rewritten in British English, following the
  SimpleEnglish (ASD-STE100) discipline.
