# [0.10.0]

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Fixed

- `make watch` and bare `air` now run the same binary. Air loads `.air.toml`
  by default and it does not load `air.toml`. The repository held only
  `air.toml`, so bare `air` ignored that file and used the air defaults. It
  then built `./tmp/main` and ran that binary instead of `./bin/ocd`. The
  configuration file is now `.air.toml`, and the `watch` target runs `air`
  with no config flag. Both ways build `./bin/ocd` and run it.

## Changed

- `README.md` and `AGENTS.md` name `.air.toml` as the file that `make watch`
  uses. The comments at the top of `.air.toml` explain that a file called
  `air.toml` is not read by air.
