# [0.1.0] - 2026-07-23

[Full release page](https://github.com/bladeacer/ocd/releases/tag/v0.1.0)

## Added

- `ocd interact` TUI to browse Obsidian versions asynchronously, with
  search, filters, and a CSS status column.
- `ocd diff` to show a colourised, scrollable diff of `app.css`
  between two versions.
- `ocd extract` to download and extract `app.css` from a GitHub release.
- `ocd clean` to wipe the cache and extracted CSS.
- `?` help overlay in both the version browser and the diff viewer.
- Pure-Go ASAR parsing, so no Docker or Node.js is required.
