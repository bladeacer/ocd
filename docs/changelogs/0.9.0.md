# [0.9.0]

[Full release page](https://github.com/bladeacer/ocd/releases)

All notable changes to ocd in this version are documented below.

The format is based on Keep a Changelog, and this project adheres to
Semantic Versioning.

## Added

- Selector comparison on `ocd check`. The command now reports how the theme's
  selectors compare with the target Obsidian version, alongside the existing
  variable report:

  ```
  Selector check: target v1.6.3 vs theme /themes/flexcyon
    target selectors:  3303
    theme selectors:    5424
    exact match:        49
    covered by theme:   461
    not covered:        2842
  ```

  `exact match` counts selectors that appear in both. `covered by theme` is
  the useful number: it counts target selectors that some theme selector
  reaches, using `core.SelectorCovers`.
- `core.SelectorReport` with `String`, `MarshalTOML`, `MarshalJSON`, and
  `MarshalYAML` methods. The selector report is exported next to the variable
  report as `ocd-check-<version>-selectors.<ext>`.
- `core.SelectorCovers` decides whether a theme selector reaches a target
  selector. A theme rule for `.workspace-leaf` reaches
  `.workspace-leaf.mod-active .cm-content`, because the theme sets the base of
  the chain even though the target names more of it. A descendant combinator
  in the theme reaches a child or sibling combinator in the target; a child
  combinator does not.
- `--no-selectors` flag on `ocd check`, to skip the selector report and its
  export.
- `core.CSSIndex.merge` combines the parse of several stylesheets, so a
  folder is read once.

## Changed

- SCSS source support was removed before release. A Sass file defines its
  palette as `$variables` that are injected at build time, and those never
  reach Obsidian, so comparing them produced results that looked
  authoritative but were not. `ReadTheme` reads CSS only, and the changelog
  for 0.8.0 was corrected.
- A comma-separated selector list is now split into its parts. Obsidian's
  `app.css` uses lists such as
  `.HyperMD-header-1, .inline-title[data-level='1'], .HyperMD-list-line .cm-header-1`,
  which were previously recorded as one selector and could never match. This
  raised the parsed selector count for the 1.6.3 target from 2594 to 3303.
- `internal/tui` entry points go through a `program` interface and a
  `newProgram` variable, so the browser, the version picker, and the diff
  viewer can be driven in tests without a terminal.
- `cmd` goes through `runInteract`, `pickVersions`, and `runViewer`
  variables, for the same reason.

## Fixed

- Obsidian's `app.css` begins with two NUL bytes. They were collected into the
  first selector, which was recorded as `\x00\x00 :root` instead of `:root`.
  Control bytes that are not ordinary whitespace are now dropped.
- A comma inside brackets or a quoted string no longer splits a selector
  list, so `[data-x="a,b"]` stays one attribute value.
- `SelectorCovers` returned true for an empty theme selector, and treated a
  child combinator as equivalent to a descendant one. Both are fixed.
- `ocd check` ignored `check_format` from a config file. The format flag
  defaults to `toml`, so the `format == ""` test that read the config never
  fired. The flag is now checked with `cmd.Flags().Changed`, as `origin` and
  `stat` already did.
- The diff viewer crashed with a nil pointer when rendering a header for a
  model with no result.
- `internal/tui` tests ran from the package directory, so a test that took the
  TLDR export path left `ocd-tldr-a-b.toml` in the source tree, which was then
  committed. The test suite now runs from a scratch directory.

## Internal

- Test coverage is 93.2%, up from 77.8%. The remaining uncovered lines are
  filesystem fault paths, such as a failing `MkdirAll` or `CreateTemp`, and
  terminal rendering branches that need a real terminal.
- Tests no longer reach the network. Three command tests were removed and
  rewritten after they turned out to call GitHub, which made the suite slow
  and dependent on the network.

## Notes

- The selector numbers are indicative rather than a verdict. Obsidian's own
  selectors are mostly CodeMirror and HyperMD internals such as
  `.HyperMD-header .cm-header-1`, which a theme rarely restyle one by one. A
  theme reaches them through other hooks. Use the variable report for a hard
  compatibility answer and the selector report for a rough sense of reach.
