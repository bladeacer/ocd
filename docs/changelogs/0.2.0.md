# [0.2.0] - 2026-07-24

[Full release page](https://github.com/bladeacer/ocd/releases/tag/v0.2.0)

## Added

- `--tldr` flag on `diff` to print a summary of CSS changes and export
  it to TOML, JSON, or YAML.
- `ocd stat` command to analyse a single version's `app.css` for
  selector count, CSS variables, colour usage, and specificity.

## Fixed

- Duplicate selectors in the exported TOML output are now deduplicated.
- `n`/`N` behaviour in the diff viewer: `n` no longer falls back to
  hunk navigation when there is no active search.
- Stat rendering: net line-count delta is now shown.
- Syntax highlighting consistency across diff view modes.
- Figlet art alignment and other minor rendering issues.
