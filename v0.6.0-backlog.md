# Backlog - v0.6.0 (Picked Up Later)

## What is done

1. **Merged versions** - `MergeVersions` in `internal/core/origin.go` merges RSS
   public desktop versions with cached CSS directory versions so stale RSS feeds
   no longer cause false "not found" results.
2. **CSS comment stripping** - `stripCSSComments` in `internal/core/origin.go`
   removes `/* ... */` comments before selector/variable matching.
3. **Batch FindOrigins** - implemented in `internal/core/compat.go`, returns
   `TargetOrigin` for each target in a single pass through sorted cached CSS.
4. **CheckCompatibility** - implemented in `internal/core/compat.go` with strict
   and relaxed modes, `VariableOrigin`/`CompatCheckResult` types, String/Marshal
   methods, and tests.
5. **CSS comment tests** - added to `internal/core/origin_test.go`.

## What remains

  targets are unknown (found in no cached version). The current `CheckCompatibility`
